Remote Desktop (Fallback)

Für Funktionen ohne native Steuerung (Plug-in-Oberflächen, Arrangement-Bearbeitung, Export-Dialog) nutzt du die in macOS eingebaute Bildschirmfreigabe (VNC) – über die sichere Tailscale-Verbindung, nie offen im Internet.

  1. Am Mac einmalig: Systemeinstellungen › Freigaben › Bildschirmfreigabe aktivieren (nur für deinen Benutzer).
  2. Auf dem Pixel einen kostenlosen VNC-Client installieren, z.B. AVNC (Open Source, F-Droid/Play Store).
  3. Verbinden mit: –
VNC-Verbindung öffnen

Touch, Maus, Zoom, Scrollen und Bildschirmtastatur stellt der VNC-Client bereit. Bildqualität im Client einstellbar (für Mobilfunk: niedrige Farbtiefe).
